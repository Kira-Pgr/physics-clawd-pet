# Dots 系列皮肤

四款角色都是平滑画风、程序生成的毛发，在托盘 **形象** 菜单里切换：

| 皮肤目录 | 形象 |
| --- | --- |
| `dots` | 蓝色云朵，斜戴黑色贝雷帽 |
| `dots-green` | 青柠绿色青蛙，眼窝与身体连成一体、黑领结 |
| `dots-yellow` | 黄色圆角饭团，细黑色椭圆眼镜、闭眼曲线、黑领结 |
| `dots-pink` | 粉色短耳兔，黑耳机、闭眼曲线、两只圆耳朵 |

四款按用户提供的参考截图调整轮廓，手脚收进身体轮廓，动作时仍可伸出。沿真实外轮廓生成散毛，按曲面方向铺短绒，光照从左上方落下。贝雷帽使用独立的深色绒面设置；眼镜、领结和耳机随身体变形，黄色与粉色保持闭眼表情。毛发贴图会缓存，呼吸和走路由引擎连续计算。

身体已进一步缩短约 17–26%，兔耳收短，毛发加入柔和底绒与弯曲的成束绒毛，避免硬边与颗粒感。

这些是可直接使用的程序绘制皮肤，不是从官网提取的原始贴图或模型。`artifacts/dots-soft-preview.png` 展示当前的大图、桌面大小、摸摸和工作姿势。

这些皮肤是同人作品，参照 [OpenAI 的 Dots](https://openai.com/index/introducing-dots/) 形象用代码画成，与 OpenAI 无关，也不代表官方。

如果你要商用或二次分发，请先确认权利人的品牌使用规定。

会做的小动作：敲代码、吃TOKEN，以及专属的抖毛；不炒股。改 `skin.json` 里的 `actions` 就能调整。

引擎和皮肤是分开的：删除任意皮肤目录，引擎和其他皮肤照常工作。

开发预览：运行 `npm run dev`，打开 `http://localhost:1420/preview.html`。
